# E-commerce Sales Analysis 📊

## 🎯 Project Objective
This project demonstrates an end-to-end data analysis workflow for an e-commerce business. The goal is to clean messy transaction data, handle missing values, and extract actionable business insights to help stakeholders make data-driven decisions.

## 🛠️ Tools & Technologies Used
* **Python**: Data manipulation and scripting.
* **Pandas & NumPy**: Data cleaning, handling null values, and aggregation.
* **Matplotlib & Seaborn**: Exploratory Data Analysis (EDA) and data visualization.
* **Jupyter Notebook**: Interactive coding environment.

## 📈 Key Steps Performed
1. **Data Cleaning**: 
   * Handled missing values in critical columns (Prices, Quantities).
   * Intelligently imputed missing discount data based on business logic.
   * Standardized date formats for time-series analysis.
2. **Exploratory Data Analysis (EDA)**:
   * **Sales by Category**: Identified top-performing product categories.
   * **Trend Analysis**: Mapped monthly sales trends to spot seasonal peaks.
   * **Customer Behavior**: Analyzed preferred payment methods across different sales locations (Online vs. Offline).
